# Course Catalog

## Purpose

为学生提供统一、按任务组织的机器人足球课程入口，使初学者能够快速体验课程演示，也使有基础的学生能够复现实验并继续改进现有算法基线。

## Requirements

### Requirement: 学生可以按任务发现课程
项目 SHALL 在统一入口列出足球踢球、S 型绕杆和 4v4 足球对抗课程，并为每门课程提供对应的介绍和操作入口。面向学生的课程名称 SHALL 使用任务名称，算法名称只能作为基线或实现背景说明。

#### Scenario: 从 README 选择课程
- **WHEN** 学生打开项目 README 并浏览课程列表
- **THEN** 学生能够通过任务名称区分三门课程并进入所选课程的介绍

### Requirement: 课程提供训练与演示指引
每门课程 SHALL 提供课程介绍和快速开始指南，说明运行训练及加载课程训练产物或维护者提供模型进行演示所需的命令、依赖和模型位置。用于演示的模型可以由冒烟训练生成，不要求达到正式训练效果。

#### Scenario: 学生开始复现课程
- **WHEN** 学生根据课程快速开始指南执行训练步骤
- **THEN** 课程文档提供足以启动该课程基线训练的命令和必要配置说明

#### Scenario: 学生运行课程模型演示
- **WHEN** 学生使用课程训练生成或获取的模型并按文档启动无头演示
- **THEN** 演示脚本能够加载该模型、运行指定步数并正常退出

### Requirement: 每门课程均可执行冒烟训练
每门课程 SHALL 提供可执行的短程训练配置，用于确认该课程训练管线能够启动并完成训练迭代。

#### Scenario: 完成课程训练冒烟
- **WHEN** 维护者按课程提供的冒烟配置运行训练
- **THEN** 训练管线启动并完成短程训练，且过程不依赖完整规模训练资源
