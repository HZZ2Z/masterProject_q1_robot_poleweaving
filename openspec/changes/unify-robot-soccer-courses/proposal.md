# Proposal

## Why

课程基线分散在 `SuperMimic`、`SuperMimicPoleWeave` 和 `MAPPO4V4` 等来源分支，学生难以从一个项目入口发现课程、运行演示或复现实验。现在将这些课程统一到当前目标分支，并按任务组织课程入口，可以让初学者快速体验，也让有基础的学生继续训练和迭代算法。

## What Changes

- 将足球踢球、S 型绕杆和 4v4 足球对抗三个课程整合到当前目标分支，并调整目录以区分课程代码和共享机器人/仿真基础设施。
- 保留来源分支的 Git 提交历史，便于后续继续合并各课程分支的新迭代。
- 记录来源分支和后续同步约定，降低课程继续迭代时重复处理历史的成本。
- 课程面向学生时使用任务名称；算法和来源分支名仅作为实现或基线背景，不作为课程名称。
- 为每门课程提供介绍、快速开始指南、训练入口和模型演示入口，保留学生迭代基线算法的空间。
- 重组 README，提供快速体验和复现实验入口、课程列表、通用环境说明，并链接到课程级说明。
- 对照三个来源分支整合 `.gitignore`，保留共享规则并加入各课程需要的产物忽略规则，避免忽略应提交的源文件或资产。
- 为每门课程定义冒烟训练和模型无头演示验收步骤。

## Capabilities

### New Capabilities
- `course-catalog`: 学生可以从统一入口发现按任务命名的课程，并进入各课程的介绍、训练和演示流程。

### Modified Capabilities

无。

## Impact

- 影响 README、课程目录、训练与演示脚本、共享环境/机器人资产与工具的组织方式。
- 需要读取并整合来源分支 `SuperMimic`、`SuperMimicPoleWeave` 和 `MAPPO4V4` 的课程内容及 `.gitignore` 规则；分支名称不会作为学生可见的课程名称。
- 依赖每门课程现有训练和演示依赖；不引入新的算法框架要求。
- 维护者提供各课程模型及其下载位置，作为无头演示验收输入。
