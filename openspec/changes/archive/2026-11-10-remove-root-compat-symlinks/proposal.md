# Proposal

## Why

仓库根目录的兼容软链接数量较多，掩盖了 `courses/` 与 `shared/` 的真实源码归属，让目录结构显得杂乱。现在课程实现已集中到规范目录，可以同步迁移仓库内依赖并移除这些链接，降低维护者判断入口与修改位置的成本。

## What Changes

- **BREAKING** 将仓库内 Python 导入、课程命令、Docker 配置、测试、辅助脚本和文档从根目录兼容入口迁移到 `courses/`、`shared/` 下的规范位置。
- 为课程命令和共享模块建立清晰、可复现的 Python 路径配置，不依赖根目录软链接或当前目录碰巧提供的导入路径。
- 删除所有由 Git 跟踪的仓库根目录兼容软链接，并更新维护清单，记录新的导入、运行方式和目录边界。
- 验证课程入口、测试收集、Docker 启动配置及资源路径在新布局下可解析；同步记录旧入口的迁移说明。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。此次变更只调整源码路径、导入配置、命令入口和文档，不改变课程运行时行为，因此设置 `skip_specs: true`。

## Impact

影响仓库根目录软链接、`courses/` 与 `shared/` 下的 Python 导入和资源路径、测试与辅助脚本、Docker 启动命令、README 和维护清单。课程算法、配置语义、模型与训练行为保持不变；根目录旧命令和导入名将不再作为受支持入口。
