# Proposal

## Why

仓库根目录混放课程实现、共享训练框架和课程入口，难以快速判断文件归属；课程代码还可能在根目录与 `courses/` 内各维护一份，增加修复遗漏和行为分叉的风险。本次整理明确唯一实现位置，减少重复维护，并让根目录聚焦仓库级入口与配置。

## What Changes

- 将课程专属实现归入各自的 `courses/<课程>/`，共享实现归入 `shared/`。
- 对现有根目录导入名，优先通过兼容链接或轻量包装维持，不复制实现；具体兼容方式在设计中确定。
- 核查并消除 `q1_supermimic`、`q1_4v4` 等候选目录的重复实现；保持 Python 导入名及现有命令入口可用，除非迁移盘点证明无需兼容。
- 检查 `q1_slalom` 的版本控制和引用情况；当前未发现受 Git 跟踪的源码或项目引用，实施时将再次确认并清除无用缓存目录。
- 更新引用路径、文档和目录归属清单，确保每份实现只有一个规范来源。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。此变更只调整仓库布局与维护方式，不改变课程运行行为，因此本变更设置 `skip_specs: true`。

## Impact

影响仓库文件布局、Python 导入与脚本路径、测试导入、课程文档和维护清单。运行时行为、模型算法和课程配置语义保持不变；实现时需盘点符号链接、包装入口及脚本对仓库根目录的定位方式。
