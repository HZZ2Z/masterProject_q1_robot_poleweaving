# Proposal

## Why

项目 README 目前偏向已有使用者，第一次接触的学生难以快速理解课程差异、选择上手路径并完成环境安装。将课程导航、环境准备和课程操作入口按新手的阅读顺序组织，可以降低首次运行门槛。

## What Changes

- 将根 README 调整为课程主页，介绍项目、学习路径和三门课程的任务差异。
- 新增统一环境搭建指南，说明前置条件、子模块、Conda 环境、安装验证和常见问题，并区分基础体验与正式训练的硬件要求。
- 统一各课程 README 的入门信息和结构，链接到环境指南，并提供按课程选择后的最短体验入口。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。此变更只调整文档内容与导航，不改变课程运行行为。

## Impact

影响根目录 `README.md`、三门课程的 README，以及新增的环境搭建文档。无需修改程序、依赖或运行接口。
